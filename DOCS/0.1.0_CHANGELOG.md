# 0.1.0

## [0.1.0] - 2026-09-20

### Added

- Add Gradle scaffold with `common` and `paper` modules, Java 25 toolchain, Shadow jar and run-paper task for Minecraft 26.3.
- Add boot screen with pastel blue palette and module plus integration load list through Adventure components.
- Add translation system with translation keys, English and Spanish files and fallback to English.
- Add update checker against GitHub tags with async notice on boot; offer pre-releases only to pre-release servers.
- Add dialog framework with dialog model, pastel palette, native Paper renderer and manager with dialogs toggle and chat fallback.
- Add single root command `/zn` with one subtree per module and a short alias.
- Add Auth module with register, login, logout, unregister, delacc, changepassword, email add and change, TOTP setup, confirm and disable, OTP generate and verify, PIN set, verify and reset, remember on and off, captcha challenge and answer, verification issue and confirm, premium, cracked and freemium modes, getlogs and admin reload, purge and forcelogin; use BCrypt hashing, 12h IP sessions and 3 accounts per IP; lock movement, blocks, chat, commands, inventory and damage before login and allow only `/zn help`, `/zn auth` and `/zn antibot` pre-login.
- Add Antibot module with pre-login throttle, name and blacklist checks, manual block list, panic mode and status report.
- Add TAB module with player list header and footer, per-player teams for nametags, join bossbar and info, reload and toggle commands.
- Add Essentials module with spawn, homes, warps, tpa, tpahere, tpaccept, tpdeny, tpaall, tpacancel, tpo, tphere, tpall, tppos, tpr, settpr, tptoggle, back, top, bottom, jump, kits with cooldowns persisted to disk, jails with movement lock persisted to disk, mute and unmute, mail persisted to disk, nick and realname, motd, rules, seen, whois, msg, reply, msgtoggle and socialspy, heal, feed, fly, god and suicide, workbench, enderchest, disposal and hat, ping, getpos and near, time, weather, speed and gamemode, repair, more, extinguish, burn, lightning and thunder, broadcast and helpop, sudo, kill, kick, kickall and vanish.
- Add Chat module with 100-block local chat and shout toggle, chat hide toggle, `[item]`, `[inv]` and `[ender]` showcases and placeholders menu dialog.
- Add Inventory module with see, endersee, clear, enderclear, clone, enderclone, give and endergive for online players, death backup with rollback restore and admin reload.
- Add Clans module with create, disband, invite, accept, kick and leave, ally and rival, war start and end, ranks, home, description, verify, ban and unban, personal, clan and global friendly fire, bulletin board, stats, roster, list and lookup, regroup, trust and untrust, member mute, banner, kills and mostkilled, coords, vitals, rivalries and profile, rename and locale.
- Add ItemEdit module with rename, lore add, set and clear, enchant, unbreakable toggle, attribute add and remove, custommodeldata, flags, storage save, get, delete and list, serveritem create and give, info, encoded import, reload and editor menu dialog.
- Add integration detection for LuckPerms, Geyser, Floodgate and PlaceholderAPI with boot report.
- Add premium auto-login: detect offline UUIDs to skip password for premium accounts in premium and auto modes while cracked mode always asks for password; apply on join with default auto mode for new accounts.
- Add `/zn debug` command with self-tests for translation, auth, clans and file areas, reporting pass and fail counts.
- Add unit tests for AuthService, ClanService and translation completeness in both languages.
- Add warpinfo, renamehome and powertool bind, toggle and list commands backed by the existing data and listener.
- Add regroup teleporting online clan members to the caller with a gathered count.
- Add weekly Dependabot updates for GitHub Actions and Gradle dependencies with the repository commit prefix.
- Add JAR artifact upload to the publish job so a built release is retained for 30 days.

### Changed

- Consolidate the ci, governance, publish and release workflows into a single Zellys Nexus workflow with conditional jobs.
- Update all workflow actions to actions/checkout v7, actions/setup-java v6, actions/setup-python v7, actions/upload-artifact v7 and softprops/action-gh-release v3.

### Fixed

- Fix every confirmation message rendering a literal `%s` by passing the acting names, counts and coordinates.
- Fix clan stats, roster, list and lookup crashing on format mismatch by passing the real clan figures.
- Fix teleport, warp, home, kick, heal, feed and item messages showing unresolved placeholders.
- Fix kick using a hardcoded reason by accepting an optional reason argument.
- Fix whois reporting a fake IP by reading the real connection address.
- Fix seen reporting epoch millis by tracking real quit times with elapsed formatting.
- Fix rules shipping hardcoded English by moving the text into the translation files.
- Fix gamemode, vanish, socialspy, tptoggle, jail return and kit cooldown gaps by wiring each to its real behavior.
- Fix email recover sending a hollow confirmation by issuing a verification code and resetting the password on confirm.
- Fix pre-login lockdown allowing the whole `/zn` tree and blocking the legacy `/auth` command.
- Fix inventory reload claiming work by purging backups of offline players.
- Fix auth admin reload claiming work by re-reading the data file.
- Fix LuckPerms info crashing when present by passing all four format arguments.
- Fix the update check, the TAB join bossbar and the unlimited block refill using the Bukkit scheduler, which Folia rejects, by moving them to Paper's async and entity schedulers.
- Fix commands that change another player, a world's time or weather, or reapply TAB running that change on the caller's thread by running it on the thread that owns the target.
- Fix TAB failing on every join on Folia by skipping nametag teams, which Folia does not support.
